「思いついた時に描けない」を、なくす

作図ツールは PC 前提で、ひらめきは電車の中や布団の中でやってきます。A案・B案を比べたいのに、コピーした図が散らばって、どれが最新かわからなくなる。それをやめるための手帳です。

BoxLine

その場で図に、案は枝分かれで管理

指で描いた四角と線が、その場で箱と矢印になります。「ここから案を分ける」で B案 を作り、差分は色で表示。決めたら「採用」で元の図に反映。全操作が履歴に残ります。

できること

考えを図にして、育てる

描くだけで図になる

1本指で四角を描くと箱に、箱から箱へ線を引くと矢印になります。モード切替はありません。丸・菱形・筒・雲も認識します。

案を分けて、比べて、決めるPro

「ここから案を分ける」で A案・B案を作り、差分を色で重ねて比較。決めた案を「採用」すれば元の図に反映されます。

文章や音声から AI が図にする

「ユーザーが注文すると、サーバーが在庫を確認して…」と書くか話すだけ。AI が箱と線に起こし、新しい案として追加します。上書きはしないので安心して試せます。

全操作が履歴に残る

タイムラインで過去の状態に戻って眺め、そこから案を分けることもできます。無料版は直近 20 操作、Pro は最初の一筆まで。

手帳として積み上がる

図は日付順に並び、一行メモを添えられます。ロック画面のウィジェットから「描く」「話して図にする」をすぐ開けます。

draw.io にも、テキストにもPro

PNG / SVG / draw.io / テキスト（Mermaid）に書き出し。draw.io の図の取り込みにも対応。PNG 書き出しは無料版でも使えます。

やりとりの流れ（シーケンス図）も指で

参加者を描いて、ライフラインからライフラインへ線を引くだけでメッセージになります。順番の入れ替えは一覧から。

テキストで書いても図になる

「ユーザー -> サーバー: 注文」と 1 行ずつ書いて適用。慣れている方は手の上で速く設計できます。手描き・AI と混在できます。

いつ何をやるかも、同じ手帳で

何を作るか（iOS / Web）と目標リリース日を決めると日程が組まれ、「リリースまであと N 日」と今日やることで伴走します。App Store 提出の手順つき。

「整える」で自動整列

線の向きから流れを読んで、箱を等間隔に並べ替えます。気に入らなければ元に戻すだけ。テンプレートも 6 種類。

iCloud 同期Pro

あなたの iCloud だけに保存され、開発者はアクセスできません。無料版でも手帳まるごとの書き出し・読み込みでデータを持ち出せます。

分析 SDK も広告もなし

通信するのは AI 図解を使ったときの中継サーバーだけ。送った文章は生成にだけ使い、保存しません。ログインも不要です。

案を分ける

色で比べて、採用

案は Git のブランチのように枝分かれします。差分は追加が緑、削除が赤、変更が黄。比べて決めたら、採用した案の内容で元の図が更新されます。

使い方

3 ステップで、案を決める

描く、または話す

四角と線を指で描くか、「文章から図にする」に話しかけます。箱と矢印になります。

案を分ける

右上の案チップから「ここから案を分ける」。B案 で自由に変えても main は無傷です。

比べて採用

「差分」で色を見ながら決め、「採用」で元の図に反映。draw.io やテキストにも書き出せます。

FAQ

よくある質問

iPad で使えますか

iPhone 専用です。iPad には対応していません。

認識がうまくいかないときは

認識に失敗した線は手描きのまま残ります。認識直後に出る「取り消す」で手描きに戻すこともできます。設定で認識感度を 3 段階から選べます。

AI 図解に送った文章はどこへ行きますか

開発者の中継サーバー（Cloudflare Workers）を経由して Anthropic 社の API に送られ、図の生成にだけ使われます。中継サーバーには保存しません。回数の管理のため、アプリが生成したランダムな端末 ID と当月の回数だけをサーバーに置き、翌月以降に自動で消えます。

AI が起こした図で元の図が壊れませんか

壊れません。結果は必ず新しい案として追加されます（空の図の場合だけ main に直接入ります）。手で直せますし、要らなければ案ごと消せます。

Pro をやめたらデータはどうなりますか

図はそのまま端末に残り、無料版の範囲で使い続けられます。「手帳をまるごと書き出す」は無料版でも使えるので、いつでも自分のデータを .boxline ファイルとして持ち出せます。

機種変更したらどうなりますか

Pro の iCloud 同期を使っているなら新しい端末でそのまま。使っていなくても、手帳の書き出し・読み込みで移せます。Pro の購入は App Store の「購入を復元」で引き継げます。

draw.io の図を続きから描けますか

Pro なら .drawio / .drawio.svg を取り込めます。BoxLine にない図形は四角として読み込みます。書き出した draw.io ファイルは app.diagrams.net でそのまま開けます。
