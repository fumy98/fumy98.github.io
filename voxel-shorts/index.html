voxel-shorts

自分のチャンネル専用の YouTube 動画アップロードツール（YouTube API Services を使用）

voxel-shorts は、Fumiya Sakaino が運営する YouTube チャンネル「遭難事件簿 アニメで分かる実話事故解説（@sonan-jikenbo）」に、運営者自身が制作した動画をアップロードするための個人用ツールです。運営者のパソコン上でだけ動くコマンドラインのプログラムで、一般には公開・配布していません。

できること

  • 運営者が制作した動画（本編・ショート）を、YouTube Data API の videos.insert でアップロードする
  • タイトル・説明・タグを設定する
  • サムネイル（thumbnails.set）と日本語字幕（captions.insert）を設定する

他人のチャンネルや他人のデータには一切アクセスしません。視聴データ・コメント・他のユーザーの情報は取得しません。

YouTube API Services の利用について

本ツールは YouTube API Services を使用しています。本ツールを使うことで、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いは Google プライバシーポリシーをご覧ください。

voxel-shorts

A private upload tool for the owner's own channel (uses YouTube API Services)

voxel-shorts is a personal command-line tool used only by its operator, Fumiya Sakaino, to upload self-produced videos to the operator's own YouTube channel, 遭難事件簿 アニメで分かる実話事故解説 (@sonan-jikenbo). It runs only on the owner's computer and is not offered or distributed to anyone else.

What it does

  • Uploads the owner's own videos (long-form and Shorts) with the YouTube Data API videos.insert
  • Sets the title, description and tags
  • Sets a custom thumbnail (thumbnails.set) and Japanese captions (captions.insert)

It never accesses other users' channels or data. It does not read viewer data, comments, or any other user's information.

Use of YouTube API Services

This tool uses YouTube API Services. By using this tool, you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.
