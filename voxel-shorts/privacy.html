プライバシーポリシー

voxel-shorts（YouTube 動画アップロードツール）

YouTube API Services の利用

本ツールは YouTube API Services を使用しています。本ツールの利用者は YouTube 利用規約に拘束されます。Google によるデータの取り扱いについては Google プライバシーポリシー（http://www.google.com/policies/privacy）をご覧ください。

利用者

本ツールの利用者は運営者（Fumiya Sakaino）本人だけです。運営者が管理する YouTube チャンネル「遭難事件簿 アニメで分かる実話事故解説（@sonan-jikenbo）」に、運営者が制作した動画を上げるためだけに使います。一般のユーザーには提供していません。

アクセスする情報

  • Google アカウントの認可（OAuth 2.0）で発行されるアクセストークンとリフレッシュトークン。権限は youtube.upload と youtube.force-ssl の2つです。
  • アップロードの結果として YouTube から返される動画 ID と公開状態。

本ツールが YouTube に送るのは、運営者が自分で作った動画ファイル・タイトル・説明・タグ・サムネイル・字幕だけです。視聴者の情報、コメント、再生数などの統計、他のユーザーやチャンネルの情報は取得しません。

情報の使い道と共有

上記の情報は、運営者のチャンネルへの動画のアップロードと、同じ動画を二重に上げないための確認にだけ使います。運営者以外の個人・企業・サービスには、販売・共有・送信しません。本ツールにはサーバーがなく、広告・アクセス解析・Cookie・端末の追跡は一切使いません。

保存場所と保存期間

  • トークンは運営者のパソコン内のファイル（本人だけが読める権限）にだけ保存し、外部には送りません。認可が有効な間だけ保持します。
  • アップロードの記録（動画 ID とタイトル）は、二重投稿を防ぐために運営者のパソコン内に保存し、30日以内に削除または最新の情報に更新します。

アクセス権の取り消しとデータの削除

本ツールへのアクセス許可は、いつでも Google のセキュリティ設定ページ（https://security.google.com/settings/security/permissions）から取り消せます。取り消した場合、または運営者がツールの利用をやめた場合は、保存しているトークンとアップロードの記録を7日以内に削除します。なお、この削除で YouTube 上の動画やデータは削除されません（YouTube 上の動画は YouTube Studio で管理します）。

Privacy Policy

voxel-shorts (YouTube upload tool)

Use of YouTube API Services

This tool uses YouTube API Services. Users of this tool are bound by the YouTube Terms of Service. For how Google handles data, see the Google Privacy Policy (http://www.google.com/policies/privacy).

Who uses this tool

The only user of this tool is its operator, Fumiya Sakaino. It is used solely to upload videos the operator produces to the YouTube channel the operator manages, 遭難事件簿 アニメで分かる実話事故解説 (@sonan-jikenbo). It is not offered to the general public.

Information accessed

  • The OAuth 2.0 access token and refresh token issued when the operator authorizes the tool with the operator's Google Account. The scopes are youtube.upload and youtube.force-ssl.
  • The video ID and privacy status that YouTube returns after an upload.

The tool sends YouTube only the operator's own video files, titles, descriptions, tags, thumbnails and captions. It does not collect viewer information, comments, statistics such as view counts, or any data about other users or channels.

How information is used and shared

This information is used only to upload videos to the operator's channel and to avoid uploading the same video twice. It is never sold, shared or sent to any person, company or service other than the operator. The tool has no server and uses no advertising, analytics, cookies or device tracking.

Storage and retention

  • Tokens are stored only in a file on the operator's computer that only the operator can read, and are never sent anywhere else. They are kept only while the authorization is active.
  • Upload records (video ID and title) are stored on the operator's computer to prevent duplicate uploads, and are deleted or refreshed within 30 days.

Revoking access and deleting data

Access granted to this tool can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. If access is revoked, or the operator stops using the tool, the stored tokens and upload records are deleted within 7 days. This does not delete videos or data on YouTube itself (videos on YouTube are managed in YouTube Studio).
